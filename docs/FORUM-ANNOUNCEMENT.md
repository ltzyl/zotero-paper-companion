# Paper Companion: bilingual reading and local summaries for Zotero 10 (test release)

Paper Companion is an independent, AGPL-licensed Zotero plugin for Chinese academic reading. It attempts original PDF retrieval, creates a separate Chinese PDF for independent side-by-side reading, translates selected text and abstracts, generates editable summaries with local Ollama/Qwen3, and shows directed citation relationships between items already in the library.

Repository and installation: https://github.com/ltzyl/zotero-paper-companion
Downloads: https://github.com/ltzyl/zotero-paper-companion/releases

This is an early public test release. The plugin requires Python 3.12+, a separate local translation process, and Ollama with qwen3:4b for summaries. Bing translation sends text to an external service; the summary model runs locally. Optional journal indicators come from a third-party public source and are not bundled or guaranteed. No registration or model API key is required for the configured workflow.

All repository examples are fictional. Please do not attach private PDFs, library databases, connection files, or service logs when reporting issues. Initial macOS / Zotero 10 testing is documented; Windows and Linux have not been validated on real machines.

This is a community project, not an official Zotero product or endorsement.
