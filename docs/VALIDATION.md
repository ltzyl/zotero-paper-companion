# 0.1.0 验证范围

验证日期：2026-10-29。

- 9 项 JavaScript 测试：原文筛选、用户编辑保护、有向引用、文本分块、空数据集、首次启用门槛、期刊更新开关、Ollama 暂时不可用标记、虚构演示脚本语法。
- 5 项 Python 测试：服务令牌与 Origin 拒绝、路径限制、任务恢复、PDF 输入验证、引擎调用及输出协议。
- 在独立临时 Zotero 10.0.6 / macOS 文库中验证 XPI 加载、默认禁用、设置菜单、三列注册、右侧图谱面板和图谱 HTML 生成。测试没有读取用户文库。
- 使用虚构英文句子完成一次 Bing 翻译；使用全新的一页虚构 PDF 完成真实引擎翻译，得到一页可提取中文文本的独立 PDF。
- 白名单构建 XPI 与本机运行组件；对发布源码和归档内容执行隐私扫描，未发现个人文献、文库键、个人路径或凭据。具体私有对照内容不进入仓库。

边界：不是每篇真实论文的质量保证；完整 Python 安装流程未在一台全新电脑上验证。Windows/Linux 尚未实机验证；模型总结存在幻觉风险；第三方翻译和期刊数据的可用性无法保证。安装后若遇到问题，请只提供去隐私化的复现步骤。
